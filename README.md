# VoxProduct — SaaS-платформа аналитики фидбека

Интерактивный MVP-прототип клиентской части (Frontend) аналитической панели продакт-менеджера, разработанный в рамках магистратуры по направлению **09.04.04 Программная инженерия**.

## 🛠️ Стек технологий
* **Фреймворк:** React 18+ (JavaScript / JSX)
* **Сборщик проекта:** Vite
* **Маршрутизация:** React Router DOM v6
* **Стилевое оформление:** Чистый CSS, адаптивная Flexbox-верстка
* **Дизайн-система:** Premium Dark UI 

## 🕹️ Функционал MVP
1. **Полноценный User Flow (SPA):** Бесшовные переходы между 5 экранами (`/` Лендинг, `/login` Вход, `/register` Регистрация, `/dashboard` Аналитика, `/feed` Лента) без перезагрузки страниц.
2. **Имитация работы ИИ (Loading Screen):** При переходе в ленту фидбека автоматически запускается анимированный спиннер загрузки на 1.5 секунды, симулирующий обработку данных нейросетью.
3. **Клиентская фильтрация отзывов:** На странице Ленты реализовано реактивное управление состоянием (`useState`). Пользователь может мгновенно фильтровать таблицу отзывов по ИТ-категориям (*Баги, Цена, UI/UX*).
4. **Адаптивность под планшеты:** Интерфейс оптимизирован под разрешения от 768px до 1279px (карточки перестраиваются в одну колонку, боковое меню сворачивается в интерактивную кнопку-«бургер» ☰).

## 🚀 Инструкция по локальному запуску

Для запуска проекта на вашем компьютере должны быть установлены среда **Node.js** и система **Git**.

### 1. Клонирование репозитория
Откройте терминал/консоль и выполните команду для скачивания проекта:
```bash
git clone https://github.com
```

### 2. Переход в папку проекта и переключение на ветку разработки
```bash
cd VoxProductProject
git checkout feature-html
```

### 3. Установка всех необходимых зависимостей (React, Router)
```bash
npm install
```

### 4. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере появившуюся ссылку: **http://localhost:5173/**


## 🧪 Автоматизированное тестирование MVP

В рамках лабораторной работы №7 проект покрыт автоматическими компонентными тестами с использованием фреймворка **Vitest** и библиотеки **React Testing Library** для проверки ключевых функциональных требований MVP.

### 📋 Покрытые автотестами требования:
1. **Требование 1 (Реактивная фильтрация):** Проверка работы хука `useState` и функций фильтрации в ленте отзывов (`Feed.jsx`). Тест эмулирует прохождение 1.5-секундного экрана загрузки ИИ с помощью фейковых таймеров Vitest (`vi.useFakeTimers`), симулирует клик пользователя по кнопке-тегу **"🚨 Баги"** и проверяет, что из таблицы мгновенно исчезают лишние категории фидбека.
2. **Требование 2 (Адаптивное бургер-меню):** Проверка интерактивности мобильного сайдбара на панели аналитики (`Dashboard.jsx`). Тест имитирует нажатие на кнопку-«бургер» (☰) и верифицирует циклическое переключение отображения иконок меню на крестик (✕) и обратно.
3. **Требование 3 (Валидация на стороне клиента):** Аудит безопасности и защищенности формы входа (`Login.jsx`). Тест сканирует разметку DOM-дерева формы авторизации и подтверждает обязательное наличие атрибута `required` у полей ввода E-mail и Пароля для предотвращения отправки пустых данных.

### 🚀 Инструкция по запуску автотестов
Для запуска автоматических тестов локально на вашем компьютере выполните команду в корневом каталоге проекта:
```bash
npm run test
```
